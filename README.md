# Libertad Financiera

App personal de finanzas para Colombia (COP). Desarrollada con React 18 + TypeScript + Vite, compilada como HTML autónomo.

## Características
- Dashboard de patrimonio neto
- Control de ingresos y gastos
- Semáforo de deseos (presupuesto mensual discrecional)
- Gestión de deudas con estrategias Avalancha y Bola de Nieve
- Metas de ahorro con aportes mensuales
- Checklist de pagos por ciclo (reset el día 20)
- Ingresos extra variables

## Uso
Abre `index.html` directamente, o sirve con:
```
npx serve -l 3333 -s .
```

Los datos se guardan en `localStorage` del navegador.
